# NEBULAxBLOOD v2.1.0

This release adds the requested management foundations:

- Admin-configurable node display names.
- Admin-configurable node price per GB.
- Node enable/disable state and maintenance mode with message/end time.
- Checkout order API accepts an explicit node selection and calculates node-price contribution.
- Admin-configurable payment QR URL/data URL.
- Existing v2 game Docker provisioning foundation is retained.

Still not complete: production payment-provider integration, full customer authentication, automatic DNS/SRV/TCP proxying, and real VPS/libvirt provisioning.
