NEBULAxBLOOD NETLIFY-ONLY STATIC BUILD

No Git. No npm. No build command.

Upload the CONTENTS of this folder directly to Netlify Drop, or connect the folder as a manual deploy.
The site is plain HTML/CSS/JS and includes many physical .html pages.

Supabase URL and publishable key are in config.js.
Do not add service-role keys or database passwords.

For GitHub/Discord OAuth, add your Netlify site URL to Supabase Authentication > URL Configuration and enable the providers.
